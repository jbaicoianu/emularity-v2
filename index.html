Easy emulation in the browser. Each example below boots a real machine as WebAssembly, described entirely with HTML custom elements. See the README for documentation.

Doom

DOSBox

Mounts a zip from archive.org as the C: drive and launches Doom via an inline batch file, with an on-screen PC keyboard.

Chocolate Doom

Native port

The generic emulator element driving a native Emscripten port. Pick a WAD from the menu, drag and drop your own, or pass one by URL parameter.

Pac-Man

MAME Broken

Arcade emulation with a custom on-screen control panel for coin-up and player start buttons.

Apple IIe — Oregon Trail

MAME Broken

Boots an Apple IIe from a floppy disk image, loading the emulator build from a remote server.

TI-82 Calculator

MAME

A graphing calculator with a custom on-screen keypad and a themed, calculator-green loading screen.

SGI Indy — IRIX 6.5

MAME Broken

A full SGI Indy workstation booting IRIX from a CHD hard disk image. (Disk images not included — requires locally-hosted files.)
